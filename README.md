# 💭 My Mindset

I believe becoming a good programmer isn't simply about learning more programming languages.

It's about learning how to **think**.

A new language can be learned.

A framework can be learned.

A tool can be learned.

But the ability to look at an unfamiliar problem, understand it, break it down, and construct a solution is something worth developing continuously.

That's the skill I'm most interested in building.

> **Learn deeply. Think critically. Build consistently.**
